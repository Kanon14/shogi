# Shogi

A local two-player shogi game built with React, TypeScript, Vite, and Vitest.

## Development

```powershell
npm install
npm run dev
```

## Verification

```powershell
npm test
npm run build
```

## Version 1 Scope

- Local two-player play on one computer.
- Standard 9x9 board.
- Legal moves, captures, drops, promotion, check, and checkmate.
- No AI opponent or online multiplayer.
